Política de Privacidade

Última atualização: 24 de setembro de 2026

1. Identificação do Aplicativo e Contato

O aplicativo Kairos é uma plataforma dedicada a estudos, anotações e organização devocional. Levamos a privacidade e a segurança dos seus dados com rigor.

Para dúvidas, requisições de exclusão de dados ou esclarecimentos sobre esta política, entre em contato através do e-mail oficial: contato.kairosapp@gmail.com.

2. Coleta de Dados e Escopos Google OAuth

Ao realizar login utilizando sua Conta Google, solicitamos estritamente os seguintes dados de perfil público:

  • Nome completo: para identificação amigável do perfil na interface do aplicativo.
  • Endereço de e-mail: para autenticação única de conta e sincronização de dados.
  • Foto de perfil e ID de usuário Google: para personalização visual da conta e vinculação de sessão segura.

O que NÃO coletamos nem acessamos:

  • Não acessamos e-mails pessoais (Gmail), mensagens, listas de contatos ou agenda.
  • Não acessamos arquivos do Google Drive ou outros serviços não relacionados.
  • Não rastreamos geolocalização física nem coletamos dados de cartão de crédito.

3. Finalidade do Tratamento de Dados

Os dados obtidos têm as seguintes finalidades exclusivas:

  • Autenticar e manter a sessão do usuário de forma segura.
  • Vincular e sincronizar as anotações, favoritos, listas e histórico pessoal de estudos entre múltiplos dispositivos.
  • Garantir a integridade da conta e suporte ao usuário quando solicitado.

Os dados nunca serão comercializados, alugados ou transferidos a terceiros ou empresas de publicidade.

4. Conformidade com a Google API Services User Data Policy

O uso e a transferência para qualquer outro aplicativo das informações recebidas das APIs do Google pelo Kairos seguirão estritamente a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use Requirements).

Declaramos que os dados obtidos via Google não são utilizados para treinar modelos generalizados de inteligência artificial ou aprendizagem de máquina de terceiros, nem para segmentação publicitária direcionada.

5. Armazenamento, Segurança e Retenção

Adotamos práticas padrão de mercado para proteger as informações:

  • Todas as comunicações são criptografadas via HTTPS / TLS.
  • Tokens de autenticação são manipulados com segurança e nunca expostos publicamente.
  • Os dados de perfil e sincronização são mantidos apenas enquanto a conta permanecer ativa no aplicativo.

6. Procedimentos de Exclusão e Revogação de Acesso

O usuário possui controle total sobre suas credenciais e pode revogar o acesso ou excluir seus dados a qualquer momento:

  • Revogação via Google: Acesse as configurações da sua Conta Google em Permissões de Conta Google, localize o app Kairos e clique em "Remover Acesso".
  • Exclusão Completa de Dados no App: Envie um e-mail para contato.kairosapp@gmail.com com o assunto "Exclusão de Conta / Dados". Todas as preferências, marcações e dados vinculados serão permanentemente eliminados de nossos bancos de dados em até 15 dias úteis.

7. Disclaimers de Responsabilidade sobre Conteúdos

O aplicativo Kairos serve como ferramenta facilitadora de leitura e estudos. Textos, letras ou materiais históricos/religiosos disponibilizados são referências de domínio público ou integrados com finalidade exclusivamente informativa/educacional. O aplicativo não se responsabiliza por interpretações individuais ou uso indevido dos materiais catalogados.
